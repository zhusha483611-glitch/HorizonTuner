# 多段式加速修复与验证文档（RT 自动）

## 修复目标

- 消除 “多段式加速（RT自动）” 线程问题导致的静默失效。
- 提升故障可观测性：能在诊断面板快速区分是 Hook/输入/写入/异常哪一类问题。
- 优化手感：各加速段切换更平滑，段边界附近减少抖动与阶梯感。

## 参数建议（用于调参/验收口径）

- RT 触发阈值：8%~15%（过高会导致 pressed 难触发）。
- maxKmh（分段上限）：建议 260~420；越低越早进入中/高速段，越高越久停留低速段。
- 段边界：`stage1End` 建议 0.22~0.32，`stage2End` 建议 0.60~0.75。
- 目标强度：`targetFrac` 建议 `stage1` 0.70~0.85，`stage2` 0.93~0.99。

## 验证步骤与通过标准

### A. 编译/自动化回归（已完成）

- Debug 构建通过。
- 单元测试通过（32/32）。

### B. 运行时白盒验证（需要在游戏环境执行）

1. 启动游戏并确保右上角 Attached=On，进入驾驶场景。
2. 打开 Handling → 速度区域 → 打开 “多段式加速（RT自动）”。
3. 打开 “高级诊断/自检修复” 与 “速度高级诊断”（如有）。
4. 按 RT 并保持稳定输入（建议 30%/60%/100% 三档），观察：
   - 简易诊断：`速度模式=Multi` 且 `loop=Y write=Y pressed=Y`，`state=Ok`。
   - 若非 Ok：`state` 应明确指向 `HookOff/StateFail/WriteFail/Ex:*` 之一。
5. 随车速上升跨越 `stage1End/stage2End` 附近时，观察高级诊断：
   - `uSpeed` 连续上升且无明显回跳；
   - `calcBoost` 随 `uSpeed` 平滑变化；
   - `mem(boost=...)` 与 `calcBoostTick` 的变化趋势一致；
   - `lastEx=` 为空或 `multiEx/s=0`。

通过标准（建议作为验收口径）：
- 功能性：pressed=Y 时车速提升可感知，松开 RT 后加速解除（VelEnabled 清零）。
- 稳定性：multiEx/s 为 0，且 5 分钟巡航无 state=Ex。
- 平滑性：段边界附近无明显阶跃/忽强忽弱；在同一 RT 档位下 boost 曲线不抖动。
