## 公式关系（数学上等价）
- 我们要做的是把“按秒倍率”`B = 1 + δ` 换算成“每次命中倍率”`b`，命中频率 `hz`：
  - **原始写法**：`b = exp( ln(B) / hz )`
  - 当 `B = 1 + δ` 时：`ln(B) = ln(1+δ)`
  - **优化写法**：`b = expm1( log1p(δ) / hz ) + 1`
- 因为 `expm1(x)+1 == exp(x)` 且 `log1p(δ) == ln(1+δ)`，所以在“无限精度数学”下两者完全一致。

## 为什么优化写法更好（浮点数值稳定性）
- 当 `δ` 很小（比如 1e-4、1e-6），`1+δ` 在 double 里会非常接近 1：
  - 直接算 `ln(1+δ)` 可能出现精度损失（"1+δ" 的低位被舍入后再取 ln）。
  - 同理 `exp(x)-1` 在 `x` 很小的时候会有灾难性消减（两个接近的数相减）。
- `log1p`/`expm1` 是专门为小量设计的数值稳定函数：
  - `log1p(δ)` 直接得到高精度的 `ln(1+δ)`
  - `expm1(x)` 直接得到高精度的 `exp(x)-1`

## 你给的例子（直观量级）
- `δ=0.001, hz=60`：
  - `b ≈ 1 + 0.001/60 = 1.000016666…`
- `δ=0.0001, hz=60`：
  - `b ≈ 1 + 0.0001/60 = 1.000001666…`
这说明“按秒归一化”之后，写入 detour 的倍率应该非常接近 1，而不是 1.001/1.0001。
