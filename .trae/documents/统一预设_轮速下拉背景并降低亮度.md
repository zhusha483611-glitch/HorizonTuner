## 现象原因（为什么“不协调/太亮”）
- 当前预设/轮速模式的 ComboBox 背景最终走的是 `ControlBackgroundBrush`。
- 在浅色主题里 `ControlBackgroundBrush` 与 `InputBackgroundBrush` 都是纯白（#FFFFFF），所以会显得“过于亮眼”，尤其在大面积浅色背景上看起来像一块突兀白块。
- 我们为了提升可读性把禁用态 `Opacity` 设为 1（避免文字发灰），这会进一步放大“亮眼/不协调”的观感。你看到的 [HandlingResources.xaml](../../MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/HandlingResources.xaml#L118-L127) 就是这个触发器。

## 目标
- 预设/轮速模式下拉：背景与 Handling 页其它输入控件一致（同一“输入面”色系），但比纯白更柔和，不再亮眼。
- 默认/禁用态仍保持文字清晰，不再靠降低透明度去“压灰”。

## 修改方案
### 1) 新增“Handling 输入面”主题色（仅供 Handling 使用，不影响全局）
- 在主题资源中各加一个 brush：
  - [LightTheme.xaml](../../MA_FH5Trainer/MA_FH5Trainer/Resources/Theme/LightTheme.xaml)：新增 `HandlingInputSurfaceBrush`（建议用更中性的浅灰，如 `#F4F4F4` 或 `Color.Neutral.100` 级别），避免偏青。
  - [DarkTheme.xaml](../../MA_FH5Trainer/MA_FH5Trainer/Resources/Theme/DarkTheme.xaml)：新增 `HandlingInputSurfaceBrush`（例如基于现有 ControlBackgroundBrush 的近似色，保持不发黑也不发亮）。

### 2) HandlingResources：让“紧凑输入控件”全部用同一输入面色
- 修改 [HandlingResources.xaml](../../MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/HandlingResources.xaml)：
  - `HandlingCompactNumericUpDownStyle`：Background 改为 `HandlingInputSurfaceBrush`
  - `HandlingCompactComboBoxStyle`：Background 改为 `HandlingInputSurfaceBrush`
  - `HandlingCompactTextBoxStyle`：Background 改为 `HandlingInputSurfaceBrush`
  - `HandlingCompactComboBoxItemStyle` / `HandlingAccentComboBoxItemStyle`：默认背景也用 `HandlingInputSurfaceBrush`，悬停/选中用更轻微的 `HighlightBackgroundBrush`（不再出现亮眼块）。

### 3) ComboBox 的禁用态改为“降对比但不变亮”
- 在 `HandlingComboBoxStyle` 的 `IsEnabled=False` 触发器里：
  - Background 使用 `HandlingInputSurfaceBrush`
  - Foreground 使用 `SecondaryForegroundBrush`
  - BorderBrush 使用 `DisabledForegroundBrush`
  - 不使用透明度压灰（或仅做很小的透明度变化），避免亮度不一致。
