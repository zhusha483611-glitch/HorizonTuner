## 本次会话算法技术文档（公式化摘要，会写进仓库）
### 1) 输入信号
- RT 原始值：`rt ∈ [0,255]`
- 阈值（百分比→字节）：`thr = PercentToTriggerByte(thrPct)`
- 油门归一化：
  - `uThrottle = clamp((rt - thr) / (255 - thr), 0, 1)`
- 车速（由速度向量 vx/vz）：
  - `speed_mps = sqrt(vx^2 + vz^2)`
  - `speed_kmh = 3.6 * speed_mps`
- 速度归一化：
  - `uSpeed = clamp(speed_kmh / maxKmh, 0, 1)`

### 2) 强度（用户输入）
- 强度输入：`Δ ∈ [0,1]`
- 基础倍率（按秒语义）：`B = 1 + Δ`（上限 2）

### 3) 线性模式（按秒目标倍率）
- `scale = clamp(scalePct,0,100)/100`
- `g = clamp(gamma,1,4)`
- `maxDelta = clamp(B-1,0,1)`
- `shaped = (uThrottle)^g`
- `boostPerSecond = 1 + maxDelta * scale * shaped`

### 4) 多段式模式（按秒目标倍率，目标点插值）
- 分段边界：`0 < e1 < e2 < 1`（Stage1End/Stage2End）
- 目标点：
  - `b0 = 1`
  - `b1 = 1 + maxDelta * f1`
  - `b2 = 1 + maxDelta * f2`
  - `b3 = 1 + maxDelta`
- 形状函数：
  - `smoothstep(t) = 3t^2 - 2t^3`
  - `shape(t, g) = smoothstep(t^g)`
- 分段插值（Lerp）：
  - 若 `u≤e1`：`t=u/e1`，`boost=Lerp(b0,b1,shape(t,g1))`
  - 若 `e1<u≤e2`：`t=(u-e1)/(e2-e1)`，`boost=Lerp(b1,b2,shape(t,g2))`
  - 若 `u>e2`：`t=(u-e2)/(1-e2)`，`boost=Lerp(b2,b3,shape(t,g3))`
- 多段式自动最终按油门混合（防止轻点就满）：
  - `boostPerSecond = 1 + (boost(speed)-1)*uThrottle`

### 5) 关键修正：把 detour 的“每帧乘法”改成“按秒感知”
- detour 生效方式是每次命中都做乘法（复利），所以必须时间归一化。
- detour 命中频率估计：
  - 读计数器 `c = VelApplyCounter`
  - `hzInstant = (c - c_prev) / (t - t_prev)`
  - EMA 平滑：`hz = hz*(1-α) + hzInstant*α`（α≈0.2），并 clamp 到 [20,240]
- 写入 detour 的每次命中倍率：
  - `boostTick = exp( ln(boostPerSecond) / hz )`

## 还可继续“更牛”的优化方向（可选）
- 数值稳定：用 `log1p/expm1` 处理小 Δ：`boostTick = expm1(log1p(boostPerSecond-1)/hz)+1`
- 自适应限幅：根据 `hz` 和 `Δ` 动态限制 `boostTick` 的最大值，避免异常 hz 造成冲击。
- 更贴近驾驶感：把 uThrottle 的混合改成带滞回/低通滤波（轻点不窜、深踩更跟脚）。
