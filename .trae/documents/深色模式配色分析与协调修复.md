## 深色模式“别扭/不协调”的根因分析
- **层级方向被反了（像“凹陷洞”）**：深色主题里卡片/容器普遍是 `CardBackgroundBrush=#2D2D2D`，而我们给 Handling 输入控件用的 `HandlingInputSurfaceBrush=#202020` 更暗（比卡片还暗）。这会让输入框看起来像被“挖空”而不是一个自然的输入面，导致明显不协调。<br/>参考：[DarkTheme.xaml](../../MA_FH5Trainer/MA_FH5Trainer/Resources/Theme/DarkTheme.xaml#L16-L63)
- **输入面色系不统一**：项目里很多页面仍用 `InputBackgroundBrush=#080808` 或 `ControlBackgroundBrush=#242424`，Handling 又引入了新的 `HandlingInputSurfaceBrush`，同时下拉项 hover/selected 还用 `HighlightBackgroundBrush=#2C2C2C`。在深色模式中这些灰阶差异很细，容易出现“这里一块更黑/那里一块更灰”的拼贴感。
- **下拉选中态区分不足**：目前紧凑 ComboBoxItem 默认背景（输入面）与 hover/selected 背景差值较小（#202020 vs #2C2C2C），深色模式下视觉反馈不够“稳”，既不够清晰也不够统一。
- **禁用态处理导致亮度突兀**：我们为了让文字不发灰把 ComboBox 的禁用态 `Opacity` 设为 1（你在 HandlingResources 看到的那段），但若背景本身取值不合适，会把“底色不协调”暴露得更明显。[HandlingResources.xaml](../../MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/HandlingResources.xaml#L120-L129)

## 改进方向（专门针对深色主题）
- **输入面应该比卡片“略亮”或至少同级**，而不是更暗：让控件看起来是“放在卡片上”的可交互表面。
- **把 Handling 页的输入面、下拉列表、下拉项 hover/selected 做成一个小体系**：统一灰阶梯度（base/hover/selected）和文字颜色（正常/禁用）。

## 具体实施计划
### 1) 调整深色主题的 HandlingInputSurfaceBrush（核心）
- 修改 [DarkTheme.xaml](../../MA_FH5Trainer/MA_FH5Trainer/Resources/Theme/DarkTheme.xaml)：
  - 将 `HandlingInputSurfaceBrush` 从 `#202020` 调整为更“贴近卡片”的中性灰（建议 `#2A2A2A`）。
  - 可选：新增两档仅 Handling 使用的状态色（避免复用 HighlightBackgroundBrush 导致不一致）：
    - `HandlingInputSurfaceHoverBrush`（建议 `#323232`）
    - `HandlingInputSurfaceSelectedBrush`（建议 `#383838`）

### 2) HandlingResources：下拉项/输入控件使用新的深色状态体系
- 修改 [HandlingResources.xaml](../../MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/HandlingResources.xaml)：
  - `HandlingCompactNumericUpDownStyle` / `HandlingCompactTextBoxStyle` / `HandlingCompactComboBoxStyle`：Background 继续引用 `HandlingInputSurfaceBrush`（无需动结构）。
  - `HandlingCompactComboBoxItemStyle`、`HandlingAccentComboBoxItemStyle`：
    - 默认 Background = `HandlingInputSurfaceBrush`
    - Hover Background = `HandlingInputSurfaceHoverBrush`（或回退到 HighlightBackgroundBrush）
    - Selected Background = `HandlingInputSurfaceSelectedBrush`
    - 文字：默认 `ForegroundBrush`，Selected 仍可保持 `ForegroundBrush` + SemiBold

### 3) 禁用态：保持清晰但更“收敛”
- 在 `HandlingComboBoxStyle` 的 `IsEnabled=False` 触发器里（当前已是 Opacity=1）：
  - Background 固定为 `HandlingInputSurfaceBrush`
  - Foreground 使用 `SecondaryForegroundBrush`
  - BorderBrush 使用 `DisabledForegroundBrush`
  - 确保禁用态不会因为透明度变化带来“忽亮忽暗”的违和感。

### 4) 验证
- Debug 编译 + IDE 诊断。
- 深色主题重点检查：
  - 输入框不再像“挖洞”，与卡片层级自然。
  - 预设/轮速下拉：默认清晰、展开不刺眼、选中态明显。

按这个计划落地后，深色模式会从“凹陷/拼贴”变成“同一输入面体系”，协调感会明显提升。
