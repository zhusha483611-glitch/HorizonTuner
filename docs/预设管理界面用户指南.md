# 预设管理界面用户指南

## 入口

- 打开路径：自有车辆 → Handling → 多段式加速（RT 自动）区域
- 点击“管理预设”进入“多段式加速预设管理”窗口

## 界面说明

### 顶部工具栏

- 搜索框：输入预设名称关键字即时过滤（快捷键 Ctrl+F 聚焦）
- 排序：支持“热门 / 最常用 / 最近使用 / 名称 / 创建时间”
- 视图切换：列表 / 卡片
- 摘要信息：展示预设数量（上限 20）、总使用次数、最近使用的预设名

### 左侧预设区

#### 列表视图

以表格展示每个预设的关键数据：

- 预设名称
- 热度（0–100）
- 使用次数
- 最近使用时间（从未使用则显示“从未”）
- 创建时间

#### 卡片视图

以卡片展示，更适合快速浏览与对比：

- 名称
- 热度
- 使用次数
- 最近使用

双击卡片可快速“应用并关闭”。

### 右侧详情面板

选择任一预设后，会显示：

- 热度、使用次数、最近使用、创建时间
- 曲线参数预览（起步/中速/高速三段）：Gamma 与强度（百分比）
- 操作按钮：应用、应用并关闭、重命名、删除、关闭

## 常用操作

### 应用预设

- 点击“应用”：应用预设但不关闭窗口
- 点击“应用并关闭”：应用预设并关闭窗口
- 双击列表行/卡片：应用并关闭
- 右键菜单：应用/应用并关闭

应用成功后系统会自动更新：

- 使用次数 +1
- 最近使用时间

### 重命名预设

- 点击“重命名”或按 F2
- 输入新名称后系统会自动处理重名（会自动追加序号避免冲突）

### 删除预设

- 点击“删除”或按 Delete
- 弹出确认后才会删除

## 快捷键速查

- Enter：应用并关闭
- Ctrl+Enter：仅应用（窗口不关闭）
- F2：重命名
- Delete：删除
- Ctrl+F：聚焦搜索框

## 热度说明（简单版）

“热度”综合考虑：

- 使用次数：越常用热度越高
- 最近使用：越近期使用热度越高；随着时间推移会逐步衰减

因此：同样使用次数下，最近用过的会排在更前；同样时间下，使用更多的会更靠前。

## 常见问题

### 1) 为什么有的预设显示“从未”？

表示该预设创建后尚未被应用过。首次应用后会记录最近使用时间与使用次数。

### 2) 旧版本保存的预设会丢吗？

不会。旧配置会自动兼容，并为旧预设补齐统计字段（如 id/使用次数/最近使用）。

### 3) 配置文件损坏会怎样？

如果系统检测到配置文件无法解析，会自动备份损坏文件并使用默认配置启动，避免启动崩溃。
