## 功能概述

### 1. 速度强度细化

**功能描述**：将速度强度控件的范围从 1-10 扩展到 1-100，提供更精细的控制，但保持最大效果不变。

**技术细节**：
- 修改 VelocityStrength 控件的 `Maximum` 属性：10 → 100
- 修改 VelocityStrength 控件的 `Value` 属性：3 → 30
- 修改计算公式：除数从 1000 改为 10000

**效果对比**：

| VelocityStrength | 修改前 maxDelta | 修改后 maxDelta | 效果说明 |
|-----------------|----------------|----------------|---------|
| 1 | 0.001 | 0.0001 | 更精细 |
| 10 | 0.01 | 0.001 | 与原来 1 相同 |
| 30 | - | 0.003 | 默认值（与原来 3 相同） |
| 100 | - | 0.01 | **与原来 10 相同** |

---

### 2. 轮速注入频率提升

**功能描述**：将轮速注入频率从 30.3 Hz 提升到约 62.5 Hz（60 Hz）。

**技术细节**：
- 修改定时器间隔：33ms → 16ms
- 计算公式：1000ms / 16ms ≈ 62.5 Hz

**效果**：
- 响应速度提升约 2 倍
- 轮速控制更流畅、更精准

---

### 3. 多段式加速预设模式名称更新

**功能描述**：将预设模式名称从"保守模式、标准模式、激进模式"改为"S1车、S2车、A车"。

**技术细节**：
- 修改 `VelocityMode` 枚举值
- 修改 UI 中的 `ComboBoxItem` 内容
- 修改 `ApplyVelocityPreset` 方法中的 switch case

**效果**：
- 更符合赛车游戏场景的命名
- 便于玩家理解和选择

---

### 4. 动态预设保存系统

**功能描述**：实现用户自定义预设的保存、加载、删除和重命名功能。

**技术细节**：
- 创建 `VelocityPreset` 数据模型
- 在 `HandlingAutoConfig` 中添加 `CustomVelocityPresets` 列表
- 创建预设管理对话框（`PresetManagerWindow`）
- 创建输入对话框（`InputWindow`）

**功能特性**：
- ✅ 支持保存任意数量的自定义预设
- ✅ 每个预设都有可编辑的名称
- ✅ 通过预设管理对话框管理预设（删除、重命名、应用）
- ✅ 所有预设自动保存到配置文件

using System.Windows;
using MA_FH5Trainer.Models;
using MA_FH5Trainer.Resources.Config;

namespace MA_FH5Trainer.Views.Windows;

/// <summary>
/// 预设管理窗口
/// </summary>
public partial class PresetManagerWindow : Window
{
    private readonly Action<Models.VelocityPreset> _applyPresetCallback;

    public PresetManagerWindow(Action<Models.VelocityPreset> applyPresetCallback)
    {
        InitializeComponent();
        _applyPresetCallback = applyPresetCallback;
        LoadPresets();
    }

    /// <summary>
    /// 加载预设列表
    /// </summary>
    private void LoadPresets()
    {
        var config = HandlingAutoConfigManager.Get();
        PresetsListView.ItemsSource = config.CustomVelocityPresets;
    }

    /// <summary>
    /// 应用预设按钮点击事件
    /// </summary>
    private void ApplyPresetButton_OnClick(object sender, RoutedEventArgs e)
    {
        if (PresetsListView.SelectedItem is Models.VelocityPreset preset)
        {
            _applyPresetCallback(preset);
            Close();
        }
        else
        {
            MessageBox.Show("请先选择一个预设", "提示", MessageBoxButton.OK, MessageBoxImage.Information);
        }
    }

    /// <summary>
    /// 重命名预设按钮点击事件
    /// </summary>
    private void RenamePresetButton_OnClick(object sender, RoutedEventArgs e)
    {
        if (PresetsListView.SelectedItem is Models.VelocityPreset preset)
        {
            var inputWindow = new InputWindow("重命名预设", "请输入新的预设名称：", preset.Name);
            inputWindow.Owner = this;
            if (inputWindow.ShowDialog() == true)
            {
                var newName = inputWindow.InputText;
                if (!string.IsNullOrWhiteSpace(newName))
                {
                    preset.Name = newName;
                    SavePresets();
                    LoadPresets();
                }
            }
        }
        else
        {
            MessageBox.Show("请先选择一个预设", "提示", MessageBoxButton.OK, MessageBoxImage.Information);
        }
    }

    /// <summary>
    /// 删除预设按钮点击事件
    /// </summary>
    private void DeletePresetButton_OnClick(object sender, RoutedEventArgs e)
    {
        if (PresetsListView.SelectedItem is Models.VelocityPreset preset)
        {
            var result = MessageBox.Show(
                $"确定要删除预设 \"{preset.Name}\" 吗？",
                "确认删除",
                MessageBoxButton.YesNo,
                MessageBoxImage.Question);

            if (result == MessageBoxResult.Yes)
            {
                var config = HandlingAutoConfigManager.Get();
                config.CustomVelocityPresets.Remove(preset);
                HandlingAutoConfigManager.Save(config);
                LoadPresets();
            }
        }
        else
        {
            MessageBox.Show("请先选择一个预设", "提示", MessageBoxButton.OK, MessageBoxImage.Information);
        }
    }

    /// <summary>
    /// 关闭按钮点击事件
    /// </summary>
    private void CloseButton_OnClick(object sender, RoutedEventArgs e)
    {
        Close();
    }

    /// <summary>
    /// 保存预设
    /// </summary>
    private void SavePresets()
    {
        var config = HandlingAutoConfigManager.Get();
        HandlingAutoConfigManager.Save(config);
    }
}

namespace MA_FH5Trainer.Views.Windows;

/// <summary>
/// 输入对话框窗口
/// </summary>
public partial class InputWindow : Window
{
    public string InputText { get; private set; } = string.Empty;

    public InputWindow(string title, string prompt, string defaultText = "")
    {
        InitializeComponent();
        Title = title;
        PromptLabel.Content = prompt;
        InputTextBox.Text = defaultText;
        InputTextBox.Focus();
    }

    private void OKButton_OnClick(object sender, RoutedEventArgs e)
    {
        InputText = InputTextBox.Text;
        DialogResult = true;
        Close();
    }

    private void CancelButton_OnClick(object sender, RoutedEventArgs e)
    {
        DialogResult = false;
        Close();
    }

    private void InputTextBox_OnKeyDown(object sender, System.Windows.Input.KeyEventArgs e)
    {
        if (e.Key == System.Windows.Input.Key.Enter)
        {
            OKButton_OnClick(sender, e);
        }
        else if (e.Key == System.Windows.Input.Key.Escape)
        {
            CancelButton_OnClick(sender, e);
        }
    }
}

/// <summary>
/// 保存当前设置为预设
/// </summary>
private void SavePresetButton_OnClick(object sender, RoutedEventArgs e)
{
    var config = HandlingAutoConfigManager.Get();
    
    // 创建新预设
    var preset = new Models.VelocityPreset
    {
        Name = $"预设 {config.CustomVelocityPresets.Count + 1}",
        Stage1Gamma = _velocityStage1Gamma,
        Stage2Gamma = _velocityStage2Gamma,
        Stage3Gamma = _velocityStage3Gamma,
        Stage1Scale = _velocityStage1Scale,
        Stage2Scale = _velocityStage2Scale,
        Stage3Scale = _velocityStage3Scale,
        CreatedTime = DateTime.Now
    };

    // 添加到预设列表
    config.CustomVelocityPresets.Add(preset);
    HandlingAutoConfigManager.Save(config);

    MessageBox.Show($"预设 \"{preset.Name}\" 已保存", "保存成功", MessageBoxButton.OK, MessageBoxImage.Information);
}

/// <summary>
/// 打开预设管理对话框
/// </summary>
private void ManagePresetsButton_OnClick(object sender, RoutedEventArgs e)
{
    var window = new Views.Windows.PresetManagerWindow(ApplyCustomPreset);
    window.Owner = Window.GetWindow(this);
    window.ShowDialog();
}

/// <summary>
/// 应用自定义预设
/// </summary>
private void ApplyCustomPreset(Models.VelocityPreset preset)
{
    if (preset == null) return;

    // 应用预设参数
    _velocityStage1Gamma = preset.Stage1Gamma;
    _velocityStage2Gamma = preset.Stage2Gamma;
    _velocityStage3Gamma = preset.Stage3Gamma;
    _velocityStage1Scale = preset.Stage1Scale;
    _velocityStage2Scale = preset.Stage2Scale;
    _velocityStage3Scale = preset.Stage3Scale;

    // 更新 UI 控件
    if (VelStage1Gamma != null) VelStage1Gamma.Value = _velocityStage1Gamma;
    if (VelStage2Gamma != null) VelStage2Gamma.Value = _velocityStage2Gamma;
    if (VelStage3Gamma != null) VelStage3Gamma.Value = _velocityStage3Gamma;
    if (VelStage1Scale != null) VelStage1Scale.Value = _velocityStage1Scale * 100;
    if (VelStage2Scale != null) VelStage2Scale.Value = _velocityStage2Scale * 100;
    if (VelStage3Scale != null) VelStage3Scale.Value = _velocityStage3Scale * 100;

    // 切换到自定义模式
    if (VelocityModeComboBox != null)
    {
        VelocityModeComboBox.SelectedIndex = (int)VelocityMode.Custom;
    }

    // 保存配置
    var config = HandlingAutoConfigManager.Get();
    config.VelocityStage1Gamma = _velocityStage1Gamma;
    config.VelocityStage2Gamma = _velocityStage2Gamma;
    config.VelocityStage3Gamma = _velocityStage3Gamma;
    config.VelocityStage1Scale = _velocityStage1Scale;
    config.VelocityStage2Scale = _velocityStage2Scale;
    config.VelocityStage3Scale = _velocityStage3Scale;
    HandlingAutoConfigManager.Save(config);
}

## 使用方法

### 1. 使用速度强度细化

1. 打开 Handling 页面
2. 启用"多段式加速（RT自动）"
3. 在"强度"控件中调整数值（1-100）
4. 数值越大，加速强度越高

**效果**：
- 默认值 30 对应原来的 3
- 最大值 100 对应原来的 10
- 提供了 10 倍的精细度

---

### 2. 使用预设模式

1. 打开 Handling 页面
2. 启用"多段式加速（RT自动）"
3. 在"预设"下拉框中选择模式：
   - **S1车**：起步非常温和，适合湿滑路面
   - **S2车**：平衡体验，适合日常驾驶
   - **A车**：快速加速，适合竞速
   - **自定义**：用户手动调整参数

---

### 3. 保存自定义预设

1. 调整好参数（S1曲线、S1比例、S2曲线、S2比例、S3曲线、S3比例）
2. 点击"保存为预设"按钮
3. 预设会自动保存并命名为"预设 N"（N 为预设编号；如重名会自动追加后缀）

---

### 4. 管理自定义预设

1. 点击"管理预设"按钮
2. 在预设管理对话框中：
   - **应用**：选择预设后点击"应用"按钮
   - **重命名**：选择预设后点击"重命名"按钮，输入新名称
   - **删除**：选择预设后点击"删除"按钮，确认删除
   - **关闭**：点击"关闭"按钮关闭对话框

---

### 5. 应用自定义预设

1. 点击"管理预设"按钮
2. 在预设管理对话框中选择预设
3. 点击"应用"按钮
4. 预设参数会自动应用到当前设置
5. 模式会自动切换到"自定义"

---

## 已知问题和限制

### 1. 预设名称重复

**状态**：已修复。

**说明**：保存/重命名时会自动去重；如重名会自动追加后缀（如：预设 1 (1)）。

---

### 2. 预设数量无限制

**状态**：已修复。

**说明**：已限制最大自定义预设数量（默认 20 个）；超过上限会提示用户删除旧预设。

---

### 3. 预设导入/导出功能缺失

**问题**：无法将预设导出为文件或从文件导入。

**影响**：
- 无法分享预设给其他用户
- 无法备份预设

**解决方案**：
- 添加"导出预设"功能（导出为 JSON 文件）
- 添加"导入预设"功能（从 JSON 文件导入）

---

### 4. 预设预览功能缺失

**问题**：无法预览预设的加速曲线。

**影响**：
- 用户需要应用预设才能查看效果
- 不方便对比不同预设

**解决方案**：
- 添加"预览"功能，显示预设的加速曲线
- 支持对比多个预设的曲线

---

### 5. 预设分类功能缺失

**问题**：无法为预设添加标签或分类。

**影响**：
- 预设过多时难以管理
- 无法按场景组织预设

**解决方案**：
- 添加"标签"功能
- 支持按标签筛选预设

---

### 6. 轮速注入频率提升的性能影响

**问题**：轮速注入频率从 30.3 Hz 提升到 62.5 Hz，CPU 占用增加。

**影响**：
- 在低配置设备上可能影响性能
- 电池消耗增加

**解决方案**：
- 添加"注入频率"设置，允许用户自定义
- 根据设备性能自动调整频率
