# 多段式加速故障分析报告（RT 自动）

## 背景与范围

本报告覆盖 “多段式加速（RT自动）” 从 UI 开关到游戏内生效的完整链路，定位导致功能失效的根本原因，并给出修复点与风险说明。

涉及的关键模块：
- UI/事件：Handling.xaml / Handling.Velocity.cs
- 后台自动化循环：Handling.Automation.cs
- 诊断：Handling.Diagnostics.cs
- 曲线算法：VelocityCurves.cs
- Detour 变量区与写入：CarCheats.cs / CarCheatsOffsets / Memory 写入

## 现象描述

典型表现：
- UI 中已打开 “多段式加速（RT自动）”，且提示已注入/已附加；
- 实际按下 RT 时车速无明显提升，或完全无效果；
- 诊断面板可能显示 loop/tick 有增长，但 write 不增长或 state=Bad。

## 根本原因（Root Cause）

### 结论

后台多段式循环运行在非 UI 线程，但在速度归一化计算过程中间接读取了 WPF 控件 `VelocityModeComboBox.SelectedIndex`。这会触发 WPF 跨线程访问异常（InvalidOperationException），被循环内部捕获后仅计数并 Debug 输出，导致循环持续报错但不再产生有效写入，表现为 “开关开了但功能失效”。

### 证据链（代码级）

- 多段式循环由 `Task.Run` 启动，运行在后台线程：  
  [StartVelocityMultiStageAutoLoop](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/Handling.Automation.cs#L168-L173)
- 循环每 tick 会调用速度归一化：  
  [RunVelocityMultiStageAutoAsync](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/Handling.Automation.cs#L221-L233)
- 旧逻辑中，速度归一化通过 `GetVelocityModeSelection()` 读取 `VelocityModeComboBox.SelectedIndex`：  
  [GetVelocityModeSelection](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/Handling.Velocity.cs#L460-L468)
- 循环 catch 会吞掉异常，仅计数 + Debug.WriteLine，导致 UI 层面“静默无效”：  
  [RunVelocityMultiStageAutoAsync catch](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/Handling.Automation.cs#L261-L272)

## 次要触发因素（会造成“看起来无效”但非根因）

- XInput 不可用或未检测到手柄：打开开关时会被强制关闭并弹窗提示。  
  [VelocityMultiStageSwitch_OnToggled](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/Handling.Velocity.cs#L233-L249)
- detour 注入失败或 hook 失活：AOB 未命中、CRC patch 未就绪、未进入驾驶场景等。  
  [VelocityMultiStageSwitch_OnToggled 注入流程](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/Handling.Velocity.cs#L260-L322)
- 速度读取失败导致 `uSpeed` 退化：LocalPlayer 指针未更新/读数非有限。  
  [TryReadSpeedKmh](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/Handling.Automation.cs#L314-L329)
- RT 阈值设置过高：只有几乎按到底才触发 `pressed=Y`。  
  [TriggerMath](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Services/Handling/Curves/TriggerMath.cs#L5-L24)

## 影响评估与风险

- 影响范围：所有开启多段式自动加速且后台循环命中 “读取速度模式” 的场景；在特定 UI 状态/线程时序下可能 100% 复现。
- 风险：异常被吞会造成长时间无写入，用户难以判断是输入/注入/线程问题。
- 安全性：本次修复不改变 detour 字节码与内存地址，仅修复控制逻辑与诊断可观测性。
