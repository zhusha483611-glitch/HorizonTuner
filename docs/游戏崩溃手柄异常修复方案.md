### 2.1 手柄操作异常根因分析

#### 🔴 关键问题 1: XInput 库句柄未释放

**问题位置**: [xinput.cs](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Resources/Input/xinput.cs#L35-L55)

```csharp
public static class XInput
{
    private static nint _libraryHandle;  // 库句柄保存但未释放
    private static XInputGetStateDelegate? _getState;
    
    static XInput()
    {
        TryLoadXInput();  // 静态构造函数加载库
    }
    
    // 问题: 没有提供卸载/释放方法
}
```

**风险分析**:
- `_libraryHandle` 在 `TryLoadXInput()` 中被赋值，但程序生命周期内从未释放
- 使用 `NativeLibrary.TryLoad` 加载的 DLL 句柄必须通过 `NativeLibrary.Free` 释放
- 多次启动/停止可能导致句柄泄漏

#### 🔴 关键问题 2: 游戏手柄状态轮询任务缺乏异常处理

**问题位置**: [Handling.Diagnostics.cs](file:///d:/AI/MA_FH5Trainer_CN-main/MA_FH5Trainer/MA_FH5Trainer/Views/SubPages/SelfVehicle/Handling.Diagnostics.cs#L32-L115)

- 异常被静默忽略，无法知道释放是否成功
- 如果释放失败，游戏进程中会残留非法内存
