# 浅色主题设计规范（MA_FH5Trainer）

本文档描述当前项目浅色主题的设计令牌（Design Tokens）、组件视觉与交互规则、以及开发落地方式，供后续迭代与一致性维护使用。

## 1. 目标与原则

- 以“低眩光浅底 + 清晰层级 + 轻量动效”为核心体验。
- 颜色使用语义化资源键，避免在 XAML 中散落硬编码色值。
- 主要文本与主要背景的对比度以满足 WCAG 2.1 AA 为目标（正文 ≥ 4.5:1，非正文/大字 ≥ 3:1）。

## 2. 色彩体系

### 2.1 基础调色板（核心色）

这些颜色以 `LightTheme.xaml` 中的 `Color.*` 令牌为准：

| 语义 | Token | Hex | 用途 |
|---|---|---:|---|

| 主色 Hover | Color.Primary.700 | #1D4ED8 | 主要按钮 hover/强调 hover |
| 主色 Pressed | Color.Primary.800 | #1E40AF | 主要按钮 pressed/强调 pressed |
| 主色浅底 | Color.Primary.100 | #DBEAFE | 高亮/选中底色（轻） |
| 主色浅底 | Color.Primary.200 | #BFDBFE | 禁用或弱化强调（轻） |
| 背景（最浅） | Color.Neutral.50 | #F8FAFC | Window 背景、hover 背景 |
| 背景（次级） | Color.Neutral.100 | #F1F5F9 | 侧栏、分区背景 |
| 背景（三级） | Color.Neutral.200 | #E2E8F0 | 分割/pressed 背景、浅边框填充 |
| 边框 | Color.Neutral.300 | #CBD5E1 | 默认边框 |
| 禁用/弱文本 | Color.Neutral.400 | #94A3B8 | Disabled 文本/图标 |

### 2.2 状态色

| 状态 | Token | Hex | 建议用法 |
|---|---|---:|---|
| 成功 | Color.Success.600 | #16A34A | 成功提示、已连接状态 |
| 警告 | Color.Warning.600 | #D97706 | 风险提示、非致命异常 |

### 2.3 项目现有语义刷（开发使用入口）

项目 UI 请优先使用以下 Brush Key（已在浅色主题中映射到上表颜色）：

| Key | 语义 |
|---|---|
| PrimaryBrush / PrimaryHoverBrush / PrimaryPressedBrush | 主要强调/主要按钮 |
| BackgroundBrush / SecondaryBackgroundBrush / TertiaryBackgroundBrush | 背景层级 |
| CardBackgroundBrush / CardBackgroundGradient | 卡片底色 |
| ForegroundBrush / SecondaryForegroundBrush / TertiaryForegroundBrush / DisabledForegroundBrush | 文本层级 |
| BorderBrush / BorderHoverBrush / BorderFocusedBrush | 边框默认/hover/聚焦 |
| SuccessBrush / WarningBrush / ErrorBrush / InfoBrush | 状态色 |

## 3. 排版与字体

### 3.1 字体族

以系统可用字体为优先：`Segoe UI, Microsoft YaHei UI`。

| Token | 用途 |
|---|---|
| DefaultFontFamily | 正文、表单、通用文本 |
| HeaderFontFamily | 标题、区块标题 |
| MonospaceFontFamily | 数值/调试/固定宽度显示 |

### 3.2 字号层级（建议）

项目已提供 `FontSize*` 令牌；新增了可复用的文本样式（见 `DesignTokens.xaml`）：

| Style Key | 建议用于 |
|---|---|
| TextStyle.Heading | 页面/区块主标题 |
| TextStyle.Subheading | 区块副标题、分组标题 |
| TextStyle.Body | 正文、说明、段落 |
| TextStyle.Label | 标签、表单字段名、列表次级信息 |
| TextStyle.Caption | 辅助说明、注释、提示文本 |

## 4. 间距与布局

- 基础栅格单位：4px（`SpacingUnit`）。
- 建议优先用 `PaddingS/M/L` 与 `MarginS/M/L` 组合，避免不规则数值。
- 可点击/可触控目标：建议 ≥ 40px（`MinTouchTargetSize`）。

## 5. 阴影与深度（Elevation）

浅色主题通过阴影与弱边框共同表达层级：

- 卡片容器：使用 `CardGlowEffect`（默认）/ `CardGlowEffectHover`（悬停）/ `CardGlowEffectActive`（按下）。
- 轻边框：默认 `BorderBrush`，悬停 `BorderHoverBrush`，聚焦 `BorderFocusedBrush`。

## 6. 组件样式与交互状态

### 6.1 卡片容器（CommonBorderStyle）

浅色主题覆盖了 `CommonBorderStyle`，用于页面中高频“区块容器”：

- 默认：白底卡片 + 轻边框 + 阴影
- 悬停：边框略加强 + 阴影增强 + 轻微缩放（平滑过渡）

### 6.2 输入类控件（NumericUpDown / ComboBox / TextBox / ColorPicker）

推荐视觉：

- 背景：`InputBackgroundBrush`
- 边框：`BorderBrush`
- 聚焦描边：`BorderFocusedBrush`（通过 `mah:ControlsHelper.FocusBorderBrush`）

### 6.3 按钮

- 主要操作按钮：使用 `MahApps.Brushes.AccentBase`（浅色主题已桥接为 `Primary`）。
- 危险操作：建议使用 `ErrorBrush`（如关闭按钮 hover）。

## 7. 图标与图像

- 图标在浅底上应使用中性深色（与 `SecondaryForegroundBrush`/`ForegroundBrush` 同级）以保证清晰度。
- 若图标为单色路径/字体图标，建议避免纯黑，使用语义前景色刷以适配主题。
- 如后续新增位图图标：优先提供透明背景 PNG/SVG（若引入 SVG 渲染需统一方案），并确保浅底可见性。

## 8. 动效与过渡

浅色主题目前提供“卡片悬停轻微缩放”的轻量动效，用于增强可感知的层级与交互反馈，避免过度动画影响效率。

建议动效参数：

- Fast：0.1s（微交互）
- Normal：0.2s（常规 hover/focus）
- Slow：0.3s（较明显的面板切换）

对应令牌：`AnimationDurationFast/Normal/Slow`。

- 新增 UI 时：优先使用语义资源键（Foreground/Background/Border/Status），避免硬编码。
- 需要“浅色专属样式覆盖”时：放入 `LightTheme.xaml`，保证不会影响暗色主题。
