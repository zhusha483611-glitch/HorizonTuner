# 预设管理参数编辑回归检查清单

## 自动化检查

- 构建：`dotnet build MA_FH5Trainer/HorizonTuner.sln --configuration Debug`
- 测试：`dotnet test MA_FH5Trainer/HorizonTuner.sln --configuration Release`（覆盖配置迁移/预设/节流/转换器/Handling 曲线）

## 手工回归（建议逐条打勾）

### 基础交互

- [ ] 打开“预设管理”窗口无异常（不空白、不崩溃）
- [ ] 选择任意预设后，右侧出现“曲线参数（可编辑）”区域
- [ ] Gamma 输入框可编辑（步进 0.1），比例输入框以 % 展示（步进 5）
- [ ] 修改任一数值后出现“未保存修改”提示

### 保存/撤销/另存为

- [ ] 点击“保存修改”后，“未保存修改”提示消失
- [ ] 关闭窗口再打开，确认参数持久化
- [ ] 修改后点击“撤销修改”，参数恢复为原值且提示消失
- [ ] 点击“另存为新预设”，列表新增一个“副本”预设且名称自动去重

### 应用联动与统计

- [ ] 修改参数但不手动保存，直接点击“应用/应用并关闭”：应自动先保存再应用
- [ ] 应用后该预设的“使用次数/最近使用”会更新（由 Handling 页面落盘）

### 校验与稳定性

- [ ] Gamma 超出 0.1–10 或比例超出 0–100 时保存会给出提示并阻止保存
- [ ] 旧配置（无 id/useCount/lastUsedTimeUtc）启动后可正常显示并可编辑保存

### 主题与布局

- [ ] 深色/浅色主题下控件对比度正常
- [ ] 125%/150% DPI 下布局不挤压、不溢出
