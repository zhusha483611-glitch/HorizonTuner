## 功能概述

### 背景

在赛车游戏中，玩家通常会将油门（RT 扳机）按到底以获得最大加速。然而，原有的线性加速算法在油门按到底时（u=1）会导致 boost 值突然跳到最大值，产生不自然的加速爆发感，影响驾驶体验。

### 解决方案

多段式速度加速功能通过将加速过程分为三个阶段，每个阶段使用不同的曲线特性，实现更平滑、更自然的加速体验：

- **起步段（0-30%）**：温和起步，避免打滑
- **中速段（30-70%）**：线性加速，提供稳定的加速感
- **高速段（70-100%）**：平滑过渡到最大加速，避免突然爆发

### 核心特性

- ✅ **三段式曲线**：每个阶段独立的 Gamma 曲线控制
- ✅ **四种预设模式**：保守、标准、激进、自定义
- ✅ **实时响应**：30Hz 更新频率，随 RT 力度变化
- ✅ **智能互斥**：与固定加速、线性加速模式互斥
- ✅ **配置持久化**：所有参数自动保存
- ✅ **自动适应**：UI 高度根据内容自动调整

### 核心代码

#### 1. 多段式曲线算法

```csharp
private float CalculateVelocityMultiStageBoost(double u)
{
    // 阶段划分
    const double stage1End = 0.30;   // 起步段结束点
    const double stage2End = 0.70;   // 中速段结束点
    
    // 每个阶段的参数
    var stage1Gamma = Math.Clamp(_velocityStage1Gamma, 1.5d, 4.0d);
    var stage2Gamma = Math.Clamp(_velocityStage2Gamma, 1.0d, 3.0d);
    var stage3Gamma = Math.Clamp(_velocityStage3Gamma, 1.0d, 2.5d);
    
    // 每个阶段的最大 boost 增量
    var maxDelta = Math.Clamp(_velocityBoostValue - 1f, 0f, 0.2f);
    var stage1MaxBoost = maxDelta * Math.Clamp(_velocityStage1Scale, 0.1d, 0.5d);
    var stage2MaxBoost = maxDelta * Math.Clamp(_velocityStage2Scale, 0.3d, 0.8d);
    var stage3MaxBoost = maxDelta * Math.Clamp(_velocityStage3Scale, 0.5d, 1.0d);
    
    double boost;
    
    if (u <= stage1End)
    {
        // 起步段：高 Gamma，温和起步
        var u1 = u / stage1End;
        var shaped = Math.Pow(u1, stage1Gamma);
        boost = 1d + stage1MaxBoost * shaped;
    }
    else if (u <= stage2End)
    {
        // 中速段：中等 Gamma，线性加速
        var u2 = (u - stage1End) / (stage2End - stage1End);
        var shaped = Math.Pow(u2, stage2Gamma);
        boost = 1d + stage1MaxBoost + stage2MaxBoost * shaped;
    }
    else
    {
        // 高速段：低 Gamma，平滑过渡
        var u3 = (u - stage2End) / (1d - stage2End);
        var shaped = Math.Pow(u3, stage3Gamma);
        boost = 1d + stage1MaxBoost + stage2MaxBoost + stage3MaxBoost * shaped;
    }
    
    return (float)Math.Clamp(boost, 1d, 2d);
}
```

#### 3. 异步循环

```csharp
private async Task RunVelocityMultiStageAutoAsync(CancellationToken token)
{
    using var timer = new PeriodicTimer(TimeSpan.FromMilliseconds(33));
    var lastParamWriteUtc = DateTime.MinValue;
    var lastU = -1d;
    
    while (await timer.WaitForNextTickAsync(token).ConfigureAwait(false))
    {
        Interlocked.Increment(ref _velocityMultiStageLoopTicks);
        await EnsureLocalPlayerDetourAsync(token).ConfigureAwait(false);

        var address = CarCheatsFh5.LocalPlayerHookDetourAddress;
        if (address > UIntPtr.Zero && XInput.TryGetState(out var state))
        {
            var thresholdByte = GetThrottleThresholdByte();
            var rt = state.Gamepad.bRightTrigger;
            var pressed = rt >= thresholdByte;

            if (pressed)
            {
                var u = CalculateTriggerU(rt, thresholdByte);
                var boost = CalculateVelocityMultiStageBoost(u);
                var now = DateTime.UtcNow;
                
                // 降频写入：u 变化超过 0.01 或超过 100ms 才写
                if (Math.Abs(u - lastU) >= 0.01d || 
                    now - lastParamWriteUtc >= TimeSpan.FromMilliseconds(100))
                {
                    lastU = u;
                    lastParamWriteUtc = now;
                    GetInstance().WriteMemory(address + CarCheatsOffsets.VelBoost, 
                        boost, false);
                    GetInstance().WriteMemory(address + CarCheatsOffsets.VelLimit, 
                        _velocityLimitValue, false);
                }

                GetInstance().WriteMemory(address + CarCheatsOffsets.VelEnabled, 
                    (byte)1, false);
                Interlocked.Increment(ref _velocityMultiStageWriteAttempts);
            }
            else if (!pressed && _throttleMultiStagePrevDown)
            {
                GetInstance().WriteMemory(address + CarCheatsOffsets.VelEnabled, 
                    (byte)0, false);
            }

            _throttleMultiStagePrevDown = pressed;
        }
    }
}
```

## 使用方法

### 基本操作

1. **启用多段式加速**
   - 打开 Handling 页面
   - 找到"多段式加速（RT自动）"开关
   - 点击开关启用功能

2. **选择预设模式**
   - 点击"预设"下拉框
   - 选择适合您驾驶风格的预设：
     - **保守模式**：起步更温和
     - **标准模式**：平衡体验（推荐）
     - **激进模式**：更快加速
     - **自定义模式**：手动调整参数

3. **自定义参数（可选）**
   - 选择"自定义模式"
   - 调整三个阶段的参数：
     - **S1 曲线**：起步段曲线形状（1.5-4.0）
     - **S1 比例**：起步段强度比例（10%-50%）
     - **S2 曲线**：中速段曲线形状（1.0-3.0）
     - **S2 比例**：中速段强度比例（30%-80%）
     - **S3 曲线**：高速段曲线形状（1.0-2.5）
     - **S3 比例**：高速段强度比例（50%-100%）

### 使用场景

#### 场景 1：弯道出弯加速

1. 选择"标准模式"
2. 出弯时轻踩 RT（约 30-50%）
3. 逐渐加深 RT 到 70-80%
4. 完全踩下 RT（100%）进行直线加速

**效果**：起步温和，避免打滑；中速稳定，便于控制；高速平滑，无突然爆发。

#### 场景 2：直线冲刺超车

1. 选择"激进模式"
2. 直接踩下 RT（100%）
3. 享受快速加速体验

**效果**：更快的加速响应，适合追求速度的场景。

#### 场景 3：精细控制驾驶

1. 选择"保守模式"
2. 根据路况精细调整 RT 力度
3. 享受温和的加速体验

**效果**：起步非常温和，适合需要精细控制的场景。

- Gamma 值越接近 1.0，加速越接近线性
- Scale 值越大，中速段的最大加速强度越大

### 阶段 3 参数（高速段，70-100%）

| 参数 | 类型 | 默认值 | 范围 | 说明 |

**说明**：
- Gamma 值越小，高速段越接近线性，避免突然爆发
- Scale 值越大，高速段的最大加速强度越大

## 算法原理

### Gamma 曲线

Gamma 曲线是一种常用的非线性函数，用于调整数值响应曲线：

```
f(u) = u^γ
```

其中：
- `u`：归一化输入值（0-1）
- `γ`（Gamma）：曲线形状参数

**Gamma 值的影响**：

| Gamma 值 | 曲线形状 | 效果 |
|----------|----------|------|
| γ < 1 | 凸曲线 | 轻踩时效果明显，深踩时效果减弱 |
| γ = 1 | 线性 | 均匀响应 |
| γ > 1 | 凹曲线 | 轻踩时效果温和，深踩时效果增强 |

**示例**：

```
γ = 0.5:  f(u) = √u
γ = 1.0:  f(u) = u
γ = 2.0:  f(u) = u²
γ = 3.0:  f(u) = u³
```

### 多段式曲线设计

#### 阶段 1：起步段（0-30%）

**目标**：温和起步，避免打滑

**公式**：
```
u1 = u / 0.3                          // 归一化到 [0, 1]
boost = 1 + stage1MaxBoost * u1^γ1
```

**设计思路**：
- 使用高 Gamma（3.0），使轻踩 RT 时 boost 增加非常慢
- 限制最大增量（stage1MaxBoost），避免起步过猛

#### 阶段 2：中速段（30-70%）

**目标**：线性加速，提供稳定的加速感

**公式**：
```
u2 = (u - 0.3) / 0.4                  // 归一化到 [0, 1]
boost = 1 + stage1MaxBoost + stage2MaxBoost * u2^γ2
```

**设计思路**：
- 使用中等 Gamma（1.8），接近线性响应
- 累加阶段 1 的 boost 值，保证连续性

#### 阶段 3：高速段（70-100%）

**目标**：平滑过渡到最大加速，避免突然爆发

**公式**：
```
u3 = (u - 0.7) / 0.3                  // 归一化到 [0, 1]
boost = 1 + stage1MaxBoost + stage2MaxBoost + stage3MaxBoost * u3^γ3
```

**设计思路**：
- 使用低 Gamma（1.3），使加速更接近线性
- 累加阶段 1 和 2 的 boost 值，保证连续性
- 限制最大增量（stage3MaxBoost），避免突然爆发

### 曲线连续性

多段式曲线在阶段边界处是连续的：

- 在 u = 0.3 处：
  - 阶段 1 结束：boost = 1 + stage1MaxBoost
  - 阶段 2 开始：boost = 1 + stage1MaxBoost + stage2MaxBoost * 0
  - 连续性保证

- 在 u = 0.7 处：
  - 阶段 2 结束：boost = 1 + stage1MaxBoost + stage2MaxBoost
  - 阶段 3 开始：boost = 1 + stage1MaxBoost + stage2MaxBoost + stage3MaxBoost * 0
  - 连续性保证

### 归一化输入值

```csharp
private static double CalculateTriggerU(byte trigger, byte threshold)
{
    if (trigger <= threshold)
    {
        return 0d;  // 未达到阈值
    }

    if (threshold >= 254)
    {
        return 1d;  // 阈值已满
    }

    // 将 RT 值归一化到 0-1 范围
    return Math.Clamp((trigger - threshold) / (double)(255 - threshold), 0d, 1d);
}
```

**示例**：
- 阈值 = 12% → 12/100 × 255 ≈ 31
- RT = 100 → u = (100 - 31) / (255 - 31) ≈ 0.30
- RT = 200 → u = (200 - 31) / (255 - 31) ≈ 0.74
- RT = 255 → u = (255 - 31) / (255 - 31) = 1.00

## 性能优化

### 1. 降频写入

**问题**：每次循环都写入内存会导致性能下降

**解决方案**：只在参数变化时写入

```csharp
if (Math.Abs(u - lastU) >= 0.01d || 
    now - lastParamWriteUtc >= TimeSpan.FromMilliseconds(100))
{
    lastU = u;
    lastParamWriteUtc = now;
    GetInstance().WriteMemory(address + CarCheatsOffsets.VelBoost, boost, false);
    GetInstance().WriteMemory(address + CarCheatsOffsets.VelLimit, _velocityLimitValue, false);
}
```

**效果**：
- 减少内存写入频率
- 提高性能
- 不影响用户体验

### 2. UI 值缓存

**问题**：后台线程直接访问 WPF 控件会导致异常

**解决方案**：缓存 UI 值到字段

```csharp
private float _velocityBoostValue;
private float _velocityLimitValue;
private double _velocityStage1Gamma;
private double _velocityStage2Gamma;
private double _velocityStage3Gamma;
private double _velocityStage1Scale;
private double _velocityStage2Scale;
private double _velocityStage3Scale;

private void UpdateCachedUiValues()
{
    UpdateCachedVelocityValues();
    _velocityStage1Gamma = Math.Clamp(VelStage1Gamma.Value ?? 3.0, 1.5, 4.0);
    _velocityStage2Gamma = Math.Clamp(VelStage2Gamma.Value ?? 1.8, 1.0, 3.0);
    _velocityStage3Gamma = Math.Clamp(VelStage3Gamma.Value ?? 1.3, 1.0, 2.5);
    _velocityStage1Scale = Math.Clamp(VelStage1Scale.Value ?? 0.3, 0.1, 0.5);
    _velocityStage2Scale = Math.Clamp(VelStage2Scale.Value ?? 0.5, 0.3, 0.8);
    _velocityStage3Scale = Math.Clamp(VelStage3Scale.Value ?? 0.7, 0.5, 1.0);
}
```

**效果**：
- 避免跨线程访问 UI 控件
- 提高性能
- 避免异常

### 3. 异步循环

**问题**：同步循环会阻塞 UI 线程

**解决方案**：使用 PeriodicTimer 和 Task.Run

```csharp
private async Task RunVelocityMultiStageAutoAsync(CancellationToken token)
{
    using var timer = new PeriodicTimer(TimeSpan.FromMilliseconds(33));  // 30 Hz
    
    while (await timer.WaitForNextTickAsync(token).ConfigureAwait(false))
    {
        // 处理逻辑
    }
}

private void StartVelocityMultiStageAutoLoop()
{
    StopVelocityMultiStageAuto();
    _velocityMultiStageAutoCts = new CancellationTokenSource();
    _ = Task.Run(() => RunVelocityMultiStageAutoAsync(_velocityMultiStageAutoCts.Token));
}
```

**效果**：
- 不阻塞 UI 线程
- 稳定的 30Hz 更新频率
- 响应式取消

### 4. 内存保护优化

**问题**：频繁切换内存保护会影响性能

**解决方案**：使用 `removeWriteProtection: false`

```csharp
GetInstance().WriteMemory(address + CarCheatsOffsets.VelBoost, boost, false);
```

**效果**：
- 减少内存保护切换开销
- 提高性能

## 故障排除

### 常见问题

#### 1. 多段式加速功能不生效

**可能原因**：
- 游戏未运行
- 未附加到游戏进程
- 游戏版本不支持
- Detour 初始化失败

**解决方法**：
- 确认游戏正在运行
- 检查是否已附加到游戏进程
- 检查游戏版本是否支持
- 查看控制台输出是否有错误信息

#### 2. 加速效果不明显

**可能原因**：
- 阈值设置过高
- 强度设置过低
- Scale 参数设置过小

**解决方法**：
- 降低 RT 阈值（默认 12%）
- 增加速度强度（VelocityStrength）
- 增加 Scale 参数（S1/S2/S3 比例）

#### 3. 加速太快，难以控制

**可能原因**：
- 使用了激进模式
- Gamma 值设置过低
- Scale 参数设置过大

**解决方法**：
- 切换到保守模式或标准模式
- 增加 Gamma 值（使曲线更温和）
- 降低 Scale 参数

#### 4. 参数修改后没有效果

**可能原因**：
- 参数修改后未保存
- 使用了预设模式，自定义参数被覆盖
- 控件禁用

**解决方法**：
- 确认参数已保存（配置文件）
- 切换到自定义模式
- 确认多段式加速开关已启用

#### 5. UI 显示异常

**可能原因**：
- 控件未正确加载
- 空引用异常
- 布局问题

**解决方法**：
- 重新打开 Handling 页面
- 重启应用程序
- 查看控制台输出是否有错误信息
